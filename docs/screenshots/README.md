# Screenshot sources

These images show the released BIBIOCR applications. They are actual captures,
not design mockups or generated interfaces.

- `desktop-read-aloud.png`: Windows desktop 2.3.0, with a public demonstration
  text entered in the Markdown editor and spoken with Melo. The highlighted
  sentence, playback controls, speed and volume come from the running app.
- `android-home.png`, `android-result.png`, `android-compare.png`,
  `android-settings.png`: Android 0.1.6 x86_64 APK running in an Android 36
  emulator. The document was imported from the photo picker and recognized
  with PP-OCRv6. It contains public demonstration text about reading and
  organizing documents; no private documents are used.
- The OCR overview referenced from `desktop/docs/bibiocr_2.1_demo.png` is the
  existing desktop screenshot supplied by this repository.

Captured on 2026-10-04. Keep captions explicit about platform and demonstration
content when replacing these images.
